# Probing

Probing operations measure with a probe from the tool library: they probe a height grid the machine compensates for, touch off the stock top and set work Z there, trace the outline of where the plate cuts or edges of its stock and fixtures, or find a corner or centre and set the work origin there. A probing operation is a strategy, what it is to do, and a probe that can do it. The strategy names what the operation does, not who runs it: the plate's machine performs it with a cycle of its own firmware where it has one that can run there, or else with OpenSpindle's own NC, made of the machine's probing NC ([what the machine contributes](#what-the-machine-contributes)). Like every operation, a probing operation is part of a plate's program, and its NC is generated from its settings whenever the plate is compiled, so it never goes stale.

| Task        | What it does                                                        | Strategies                                                                 |
| ----------- | ------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| Height grid | Probes a grid of heights; the machine compensates later cuts for it | [Height map](height-map.md)                                                |
| Touch-off   | Touches the stock top and sets work Z0 there                        | [Z surface](touch-off.md)                                                  |
| Outline     | Traces the plate's work area or chosen edges with a laser pointer   | [Outline trace](outline-trace.md)                                          |
| Origin      | Finds a corner or centre and sets the work origin there             | [Outside corner, Inside corner, Pocket center, Boss center](3d-probing.md) |

Each strategy does one task, which decides the operation's settings.

## Probes

A probe is a library tool whose **Tool type** is Probe. Besides its dimensions it has a profile, which decides the probing it can do: **Touches**, Z only or X, Y and Z (a 3D touch probe), and **Laser pointer**, whether it carries one, which traces without touching. Both are in the tool library's editor; a tool that becomes a probe starts as Z only without a pointer. A probe whose profile is unknown probes nothing until the tool library says what it touches. The starter library has the Makera Wired Probe 2.0 (Z only, with a laser pointer) and the Makera 3D Probe (X, Y and Z, with its Ø2 mm ball). Tools from earlier library versions gain a profile when they are read: the bundled Makera probes their catalog's, another probe numbered 9999 a 3D probe's, any other probe Z only without a pointer.

A probe is bound in the plate's tool table like any tool, and the operation's NC changes to it with `M6`, so tool changes work as for cutters: the Plates list and the Job timeline show the change, and the Job tab asks to install it ([device-jobs.md](device-jobs.md)).

## Adding a probing operation

**Probing** on the Prepare toolbar opens the **Probing** dialog; **Probing** in **Add operation** shows the same list, with **All sources** back to the other sources. Both are unavailable, and say why on hover, when the plate's machine has no probing or the tool library has no probe ("The tool library has no probe.").

The list, under **Strategy**, holds the strategies in the order of the table above, each with what it does. One the plate's machine does not support ("This machine does not support Outline trace."), one that cannot run on the plate whatever its settings, and one that no probe in the library can perform ("The tool library has no probe for this.", or why the library's probe is refused, such as for its ball) is unavailable and says why on hover. Choosing one adds its operation to the selected plate, or to a new one, and selects it: named after the strategy, with its defaults fitted to the plate, and with a library probe that can perform it, the one the plate's table already holds in the number the machine needs it in, else one whose number holds no other tool, else the first. Where that probe replaces another tool in the plate's table, the strategy's item says so ([the probe's slot](#the-probes-slot)). The inspector's **Probe** changes the probe afterwards ([changing the strategy and the probe](#changing-the-strategy-and-the-probe)).

On the Z1 that gives:

| Strategy                                                  | Probe                                                                    | How the Z1 performs it                                                                                                                                                                                                                     |
| --------------------------------------------------------- | ------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Outside corner, Inside corner, Pocket center, Boss center | Touches X, Y and Z (the Makera 3D Probe), in T9999                       | The firmware's 3D probing routines (`M480`)                                                                                                                                                                                                |
| Z surface                                                 | Touches Z only (the Makera Wired Probe 2.0), in T0                       | The firmware's Z probe (`M495` with `O` and `F`) from a stored anchor, on a plate whose program sets work X and Y from its anchors ([stored anchors](stored-anchors.md#work-origin-from-an-anchor)); elsewhere OpenSpindle's `G38.2` touch |
| Height map                                                | Touches Z only, in T0                                                    | The firmware's auto-leveling: `G32`, or `M495` from a stored anchor on such a plate                                                                                                                                                        |
| Outline trace                                             | Touches Z only, with a laser pointer (the Makera Wired Probe 2.0), in T0 | OpenSpindle's trace                                                                                                                                                                                                                        |

On the Z1 none of them is ruled out by the plate: where the firmware's Z probe cannot touch, OpenSpindle's touch performs the Z surface ([Z surface](touch-off.md)).

## The probe's slot

A machine's firmware may need a probe in a particular tool number. On the Z1 a probe that touches along Z only goes in T0 and a 3D probe in T9999, the firmware's own number for it. A new probing operation selects its probe by that number (on a machine that needs none, by the probe's post-processor number, or else the lowest free one) and binds it in the plate's table. T0 and T9999 are probe slots: only a probe fills them (`tool-probe-slot`), a probe fills nothing else (`tool-probe-elsewhere`), they are never renumbered, moves made with them never cut, and assigning a tool to one in the plate's tools opens the tool library on its probes.

Each slot is one entry per plate, which every operation that uses its number shares. Putting a probe there replaces what the entry held for all of them, so both places that do it say so first:

- In the **Probing** dialog, a strategy whose probe would go in a slot holding another tool says so on its item (`Uses Makera Wired Probe 2.0, which replaces Hand-made probe in T0.`), and names the plate's operations whose strategies could not probe with that probe (`Outline trace cannot use it.`). Adding puts the probe in the slot.
- In the inspector, a probe in the **Probe** list that would replace another operation's says so on hover: "Replaces Makera Wired Probe 2.0 in T0, which 1 other operation uses.", followed by the operations it leaves without a probe they run with.

Those operations then report that their probe no longer suits them (`probing-probe`, below) until another probe is assigned.

## Changing the strategy and the probe

The inspector shows a probing operation's **Strategy** and **Probe** above its task's settings.

- **Strategy** lists the strategies of the operation's task that the machine supports, and shows only where there is more than one: on the Z1, for Outside corner, Inside corner, Pocket center and Boss center. Its hint says what the strategy does. One that cannot run on the plate is unavailable, with its reason. Another strategy keeps the operation's settings, which its own ranges then check (an origin operation's routine follows it), and an operation still named after its strategy takes the new one's name.
- **Probe** lists the library's probes that can perform the strategy on the machine. Its label's hint gives the number the operation selects it by, what it senses and, for a corner or centre, its ball (`T9999 · Touches X Y Z · Ø 2 mm ball`). A probe the strategy cannot run with stays listed while it is bound, unavailable, so the list names it (or says **No probe**, or **Missing from the library**). Choosing another puts it in the number the machine needs it in, for every operation that uses that entry.

A form shows only what the method that runs the operation reads: a Z surface that the Z1's Z probe runs leaves out **Probe travel**, as the firmware searches down to its tool rack Z ([Z surface](touch-off.md#settings)).

## Placement

A height grid, a touch-off and a corner or centre start at a placement, edited with the fields the work origin, the stock and fixtures use. **Relative to** is the **Probe position**, or one of the stored anchors of the plate's device ([stored anchors](stored-anchors.md)), with **X** and **Y** from it in machine millimetres, up to ±10,000 mm. Factory-default anchors are marked "(default)", and an anchor the plate no longer has shows as **Unavailable anchor**. Switching to the probe position and back restores the last anchor's X and Y.

- From the **Probe position**, the operation starts where the operator leaves the probe before Run; a probe change returns above it.
- From an anchor, the program travels first, as Makera Studio's probing does: up to the clearance the machine travels at (machine Z −3 on the Z1), then over the anchor plus X and Y with `G53`. When the plate's program also sets work X and Y from its anchors ([stored anchors](stored-anchors.md#work-origin-from-an-anchor)), the start is known in work coordinates too, which the Z1's own cycles use: its Z probe for a Z surface and its auto-leveling for a height map.

A corner or centre also takes an optional **Z**, the height on the bed the probe comes down to before the routine; the placement keeps a height for every task, but only the corner and centre strategies offer and read it. An outline has no placement: it traces its toolpath bounds in work coordinates, or chosen edges in machine coordinates from the plate's first anchor ([outline trace](outline-trace.md#what-it-traces)).

**Pick in the 3D view**, under the placement, starts a height map, a Z surface or a corner or centre at a point clicked on the stock, a fixture or the bed in the 3D view. The click snaps to the nearest of the strategy's targets within a few pixels, which the view marks, unless Alt is held. While the pointer moves, a label beside it gives the point's bed X and Y (from Anchor 1) and, when it snaps, the target's name, and the hint at the bottom of the view says what a click picks. The targets come from the stock's box and the enabled fixtures' solids, where they stand together:

| Strategy              | Targets                                                                                                                                                                                                                                         |
| --------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Outside corner        | The outer corners of the stock's and the fixtures' tops, each the corner it is ("Stock · back-right corner")                                                                                                                                    |
| Inside corner         | The inner corners where two walls meet around a lower pocket, on the higher wall's top: an L-bracket's ("L-bracket · thick · inner corner"), or the stock's against a fixture's wall ("L-bracket · thick · front-left inner corner with Stock") |
| Pocket center         | The holes and slots of the bed and the fixtures that nothing stands over ("Z1-MDF bed · M5 hole")                                                                                                                                               |
| Boss center           | The stock's top centre, and pins such as a dowel pin                                                                                                                                                                                            |
| Z surface, Height map | The outer corners, and the middles of the stock's and the fixtures' tops                                                                                                                                                                        |

A fixture hidden in the 3D view offers no targets and is not picked. The start is kept from the current anchor, or else Anchor 1, the bed's origin, and has no Z. A corner or centre starts where its routine is best started from what was picked, and a corner target picked for Outside corner or Inside corner sets the operation's **Corner** too ([corners and centres](3d-probing.md#settings)). Escape, or the button again, ends picking; a plate without anchors cannot pick. **Fit grid** ([height map](height-map.md)) and **Center** ([Z surface](touch-off.md)) place a grid or a touch point over the plate's work area. Before Run, an anchored placement needs the plate's anchors read from the connected machine ([checks](#checks)).

## What the machine contributes

How a machine probes is its fixture kit's `MachineProbing` (`FixtureKit.probing`); a kit without one offers no probing. It says:

- **Which probes may do which task** (`probes`): on the Z1, a 3D probe finds origins and a probe that touches along Z does everything else, as its firmware selects them.
- **The probe's slot** (`slot`): T0 for a Z probe and T9999 for a 3D probe on the Z1.
- **The NC OpenSpindle's methods are made of** (`nc`): readying a probe (on the Z1 `M5`, `G21 G90` and `M6 T…`), switching its pointer on (`M494.0`; a machine without one does not support Outline trace), the indicator around a touch (`M494.1` and `M494.2`), the travel to an anchored start (`G53 G0 Z-3`, then `G53 G0 X… Y…`; a corner or centre then waits for it with `M400`), and the touch-off's feeds and back-off (500 and 100 mm/min, 1 mm, as the Z1's configuration has them).
- **The ranges and defaults of OpenSpindle's methods on it** (`specs`, by method): one of them runs only on a machine that gives its ranges.
- **Its firmware's cycles** (`cycles`): on the Z1, the auto-leveling for Height map, the Z probe for Z surface, and the 3D probing routines for Outside corner, Inside corner, Pocket center and Boss center.
- **How its NC reads as probing in any file** (`sections`, `readers`): sections and previews.

The strategies are one fixed list (`PROBING_STRATEGIES`, `src/domain/probing/strategies.ts`). Each has an id, which the operation stores (`outside-corner`, `inside-corner`, `pocket-center`, `boss-center`, `touch-off` for Z surface, `height-map` and `outline-trace`), its task, label and description. A method (`ProbingMethod`, `src/domain/probing/strategy.ts`) performs strategies of one task: one of OpenSpindle's (`touch`, `outline`) or one of a machine's cycles (`makera-z1/z-probe`, `makera-z1/height-map`, `makera-z1/m480`). It says which strategies it performs, which machines run it (OpenSpindle's), which probe profiles it probes with, which probe tools it refuses (the routines a ball they do not take), why it cannot run on a plate with an operation's settings (the Z1's Z probe away from a stored anchor, or on a plate whose program does not set work X and Y), its parameters' ranges and defaults on the machine, which of them it reads, a new operation's settings fitted to the plate, and its NC.

A machine supports a strategy where it has a method for it: its cycles, then OpenSpindle's methods it runs (`strategyMethods`). The method that writes an operation's NC (`methodFor`) is the first of them that can run on the plate with the operation's settings, so a cycle before OpenSpindle's own; where none can, the first, whose NC then says why. A strategy cannot run on a plate only where none of its methods can (`strategyBlocked`). Which method runs follows the operation's settings and its plate, without changing the operation: a Z surface placed at a stored anchor, on a plate whose program sets work X and Y, runs the Z1's Z probe, and at the probe position OpenSpindle's touch. A probing operation whose strategy its plate's machine does not support, or which OpenSpindle does not know, keeps its settings, shows none in the inspector and reports it (`probing-unsupported`).

## Previews

The 3D view draws probing from the NC, as the plate's machine reads it, in any program: a probing operation's or an imported file's. Planned grid samples are yellow dots on the stock top, never measured heights; a touch point is a red dot; the probe's path is green, as the machine's firmware moves, its touches and searches meeting the stock and the plate's fixtures where the plate places them ([firmware-preview.md](firmware-preview.md)). Anchored starts are drawn on the bed through the plate's anchor snapshot; starts at the probe position at the work origin. The Plates list, the G-code list and the Job timeline name the probing's sections: **Height map probing** for a grid, **Z-height probing** for a touch-off along Z, **3D probing** for the 3D probe's routines and touches, **Touch-off** for a touch that moves in X or Y, and **Probe scan** for feed moves with a probe in a probe slot.

## Checks

Errors block Run; warnings inform. A probing operation whose NC cannot be generated shows the error on the operation:

| Code                  | Why                                                                                                                                                                                                                                                                                                                                                                        | Fix                                                 |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------- |
| `probing-unsupported` | The plate's machine does not probe, or does not support the operation's strategy; or OpenSpindle does not know the strategy, or it is of another task than the operation's                                                                                                                                                                                                 |                                                     |
| `probing-probe`       | The number the operation selects its probe by is not in the plate's table, holds no tool, a tool missing from the library, no probe or a probe of unknown profile; the method that runs the strategy cannot probe with that probe, the machine does not let it do the task, it is not in the number the machine needs it in, or the method refuses it (the routines' ball) | Assign a tool to the entry, else edit the operation |
| `probing-invalid`     | The method's first reason: a setting out of its range, an anchored placement without the plate's anchor snapshot or out of range, nothing to trace, no edges chosen or an edge gone                                                                                                                                                                                        | Edit the operation                                  |

For example, a 3D probe in T0 under a Z surface at the probe position reads "Z surface: T0 holds Makera 3D Probe, but the Makera Z1 does not touch off with a probe like it: assign another probe, or correct the probe's profile in the tool library."

The rest are rules in the one [rule list](workspace-model.md#rules), by task whatever the strategy, none of them configurable:

| Rules                                                                                                                                              | Stage        | Checks                                                                                                                                                                 |
| -------------------------------------------------------------------------------------------------------------------------------------------------- | ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `grid/factory-anchors`, `grid/stock-unspecified`, `grid/exceeds-stock`, `grid/outside-stock`                                                       | `operation`  | A height grid's anchors and stock ([height map](height-map.md#checks))                                                                                                 |
| `touch-off/factory-anchors`, `touch-off/stock-unspecified`, `touch-off/outside-stock`, `touch-off/before-grid`                                     | `operation`  | A Z surface's anchors, its point on the stock and its order with a grid ([Z surface](touch-off.md#checks))                                                             |
| `outline/outside-stock`, `outline/after-machining`, `outline/before-origin`                                                                        | `operation`  | Toolpath bounds beyond the stock, a trace after machining, or before a corner or centre sets work X and Y ([outline trace](outline-trace.md#checks))                   |
| `origin/factory-anchors`, `origin/start-below-top`, `origin/before-grid`                                                                           | `operation`  | A corner or centre's anchors, its start's Z against the stock and fixtures under it, and its order with a grid ([corners and centres](3d-probing.md#checks))           |
| `probing/anchors-not-read`, `probing/live-anchors-unavailable`, `probing/anchors-changed`                                                          | `run`        | An anchored placement's, or an edges trace's, anchors read from the connected machine, the plate's, and still its stored anchors; each failure offers **Read anchors** |
| `height-map/no-samples`, `height-map/size-mismatch`, `height-map/missing-samples`, `height-map/outliers`, `height-map/tilted`, `height-map/uneven` | `height-map` | A height map read at the review pause ([height map](height-map.md#reviewing-the-height-map))                                                                           |
| `tool-probe-slot`, `tool-probe-elsewhere`                                                                                                          | `tool`       | A probe in the probe slots and nowhere else                                                                                                                            |

## Opening older projects

Projects saved before format 8, and NC files exported with their setup before [plate definition](plate-definition.md) version 7, had an operation kind of their own for each of auto-level, auto Z-height, auto-scan and 3D probing. Opening one makes each a probing operation of the task it did, with the strategy that does what it did:

| Was           | Becomes                                                                                                                                                                                                                         |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Auto-level    | Height map; its width and depth become the grid's size, its probe point counts its points                                                                                                                                       |
| Auto Z-height | Z surface                                                                                                                                                                                                                       |
| Auto-scan     | Outline trace                                                                                                                                                                                                                   |
| 3D probing    | The strategy of its routine (Outside corner, Inside corner, Pocket center or Boss center), which takes its ball from the probe in T9999 instead of its own ball diameter; its distances in X and Y become one distance per axis |

Each selects the probe slot its NC selected, T0 or, for 3D probing, T9999. An operation still named after its kind ("Auto-level", "Auto Z-height", "Auto-scan", "3D probing") is named after its strategy, as a new one is. Where the plate's table has no entry for the slot, it gains one holding the library's probe for it, as adding a program that selects that number picks it (for T0 the probe numbered 0, else one not numbered 9999, else any probe; for T9999 the probe numbered 9999), or no tool when the library has none, which the table then reports. The library is the project's own; for an exported NC file, the importing app's. Groups that held a grid's section keep it under its new name, **Height map probing**.

A notice on the plate says what to review:

- an operation whose strategy cannot probe with the probe in its entry: "Auto-scan is now Outline trace, which cannot probe with Hand-made probe in T0: assign a probe it runs with.";
- a 3D probing that was set for another ball than the T9999 probe's, or whose T9999 holds no probe from the library or a probe without a ball: "3D probing was set for a 3 mm ball; it now takes the ball of the probe in T9999, Makera 3D Probe (2 mm): assign the probe you use, or correct its ball in the tool library."

Projects saved in formats 8 and 9, and exports of plate definition versions 7 and 8, named a probing operation's strategy by who wrote its NC. Opening one gives each operation the strategy that does what its own did: `surface-touch` and `makera-z1/z-probe` become `touch-off` (Z surface), `makera-z1/height-map` becomes `height-map`, `makera-z1/routines` the strategy of its routine, and `outline-trace` stays. An operation still named after its earlier strategy takes the new one's name, and its settings stay as they are ([projects](step-nc-projects.md#probing-strategies)).

The domain's probing is `src/domain/probing`: the strategy and method contracts and the machine's probing (`strategy.ts`), the strategies, the methods that perform them on a machine and new operations (`strategies.ts`), the probe an operation binds (`bound-probe.ts`), placement and picked starts (`picked-start.ts`), parameters, previews and the run rules, OpenSpindle's methods (`generic/`) and each task's parameters, planning, fitting and rules (`tasks/grid`, `tasks/touch-off`, `tasks/outline`, `tasks/origin`). The targets a start is picked on are `src/domain/plate/pick-targets.ts`. Operations resolve through `src/domain/operations/kinds.ts`. The Makera Z1's probing is wired in `src/domain/fixtures/makera-z1/makera-z1.ts`, with the NC OpenSpindle's methods are made of and their ranges in `probing-nc.ts`, its firmware's cycles in `strategies/`, and how its NC reads in any file in `wired-probe/`, `3d-probe/` and `nc-grammar.ts`. The Probing dialog is `src/features/prepare/add-operation/probing-picker.tsx`, with the probe it picks in `src/features/probing/probe-tools.ts`, the inspector's strategy and probe `src/features/prepare/inspector/probing-choice-fields.tsx`, and the task forms and their shared fields `src/features/probing`. Opening older projects upgrades probing in `src/formats/upgrade/probing.ts`, `src/formats/upgrade/strategies.ts` and `src/formats/upgrade/plate.ts`.
