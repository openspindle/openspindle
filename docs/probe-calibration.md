# Probe and anchor calibration

Device → **Anchors** offers **Auto calibrate Anchor 1** on the Z1 and **Calibrate 3D probe diameter**. Opening a guide and editing settings send no machine commands. Anchor 1 offers explicit temporary runs inside its guide; the diameter guide prepares plates to Run on Job. Saving an anchor is a separate reviewed write. Guides open in a resizable right sidebar without covering the workspace or trapping focus; Device positioning controls remain accessible. Tool libraries and write confirmations remain modal.

## Contact verification and execution

Before every G38 search or release, the host reads the firmware's actual enabled, homed XYZ soft-limit bounds with `M211` and checks both the starting position and the entire possible commanded travel. Probe-aware point transits use the same check. Missing, ambiguous, disabled or exceeded bounds refuse the move. This check is necessary because the firmware bypasses its ordinary soft-limit guard while probing. It does not establish obstacle clearance or safe probe deflection.

The same runner protects Anchor 1, diameter calibration and [part Z probing](touch-off.md#bounded-part-z-guide), including the pre-job Z option. Anchor and diameter searches use 0.4–10 mm first-search limits and a 0.1–5 mm near-surface gap range. Part Z can start from any height above the surface, with a 0.4–100 mm selected maximum on the Z1, defaulting to its profile work height and shortened to the live lower Z limit; it needs no gap estimate. Each guide includes the same safety instructions. Every measuring contact requires a fresh released input, bounded single-axis travel, successful contact report, motion drain and matching stationary coordinates; release is verified before ordinary withdrawal. The spindle stays stopped, compensation stays off and the fitted measured probe is retained. Failed, missing, ambiguous or inconsistent reports stop the run without retry or increasing bounds. Tool-setter measurement remains a separate firmware-owned cycle using its dedicated sensor and homed machine configuration; it does not prove the part-contact input.

Temporary runs that fail, stop or become invalid are dismissed automatically across all pages and guides; their error stays in Console and is shown in a notification. Lost connections wait for fresh stopped Idle telemetry with the spindle off before clearing the uncertain run. Cleanup is bound to that run's ID and never dismisses another run, unlocks the machine or starts motion. Completed valid measurements remain until the user continues or dismisses them.

Native corner, centre, height-map and stored surface operations are refused on physical connections rather than falling back to unbounded firmware probing. Their setup screens explain the restriction; simulator preparation and inspection report analysis remain available. Direct console commands, file playback and macros cannot bypass the physical execution check. Laser-only outline tracing performs no contact search.

Anchor 1 and guided diameter readings use machine-owned, bounded contact sequences instead of the firmware's long native inside-corner top search. The host requires one actual touch and release at the stationary near-surface starting position. The guide automatically watches for the untouched input, contact and removal using sequential status queries; no signal-test button or simultaneous clicking and touching is needed. It waits for a stable stationary pose before reading, scopes every read to that connection and stops watching when verified or when the positioning step closes. Pointer and keyboard interaction with Device controls pauses new reads until two seconds of quiet; an in-flight read finishes normally. A failed or ambiguous read is not retried automatically. A completed electrical touch test survives manual jogging with the same connection, probe library entry, active tool and measured tool offset. When positioning stops, the guide reads the released input again and binds execution to the new stationary XYZ. Jogging does not extend the original expiry. An incomplete touch test restarts after movement. Changing tools, sending commands other than jogging, reconnecting, a spindle start or an alarm invalidates the check. The check expires after 120 seconds and is consumed once, immediately before execution. A checkbox or a successful tool-setter measurement cannot supply it.

Every contact search requires another fresh released probe-input read between two matching stationary status reports. The host sends only one NC line at a time, requires its acknowledgement and motion drain, and correlates each successful contact with that search's directed distance and fresh stopped machine coordinates (0.003 mm tolerance). After a drain, it waits up to three seconds for a new Idle report whose XYZ matches the probe reply, because the bridge can briefly retain Run or an older Idle position. The same 0.003 mm tolerance applies to contacts, releases and no-contact positioning endpoints; an older report is never accepted and motion is never repeated. During that wait it polls status only, sends no further motion or offset commands and continues checking the measured probe, units, compensation and stopped spindle. Alarm, another unexpected state or changed prerequisites refuse continuation; missing matching Idle times out and halts with the start, command, probe reply and last stopped XYZ in the error. The input read itself still requires matching Idle reports before and after it. An unsuccessful, missing, duplicate, malformed or inconsistent contact report stops the routine before the next coordinate change or travel. It halts on execution failure, never retries, and cannot Pause/Resume between contacts; **Stop** remains available. After each measuring contact, G38.4 probes away by at most 0.2 mm at 15 mm/min, stopping when the input opens. An already released input needs no probe-away motion. The host verifies the directed release travel, successful report and a fresh released input before ordinary clearance travel; a missing release halts without retry. Release reports never enter the measurement result, which requires exactly six successful measuring contacts. The unexpected-trigger guard stays enabled and height compensation is explicitly disabled before contacts. Failure messages identify the current command and number of verified measuring contacts.

This is a software guard, not a guarantee against damage: search bounds limit commanded travel, not probe compression. An incorrect estimated gap, displaced bracket, signal failure after checking or unsuitable probe can still cause a collision. The bounded routine and its telemetry tolerance have not been verified on physical hardware. A simulator models contact geometry; it cannot validate wiring, real clearance, stopping distance or accuracy.

Unbounded native probing, old calibration drafts, altered bounded sequences and direct file/macro playback cannot bypass these checks on a physical connection. Ordinary tool measurement and machining remain available. Exported NC does not carry the host's contact checks and must not be run through another controller as a substitute.

The collision investigation found that the probe's USB lead was unplugged. The successful tool-setter measurement used a separate input. In the pinned firmware source, the native inside-corner cycle's first G38.2 search uses the configured tool-rack distance (default 108 mm), not the side-depth parameter. The new Anchor 1 sequence does not invoke that routine. The exact installed firmware version remains unconfirmed.

## Anchor 1

1. Home the machine. Secure the supplied L-bracket in its normal pinned Anchor 1 position, with clean top and inner faces. Select the fitted variant (thick, 15 mm tall, or thin, 5 mm tall) and the undamaged XYZ probe's own library entry, with tip diameter 0.5–3.2 mm. The temporary run includes the selected bracket at the front-left anchor, replacing inherited variants; no project plate is added.
2. Insert the 3D probe securely and connect its signal cable. If it is newly fitted or remounted, choose **Run tool-setter detection** in the guide and follow the machine's tool-change prompts there. This selects and measures the probe at the setter and retracts to clearance; it does not position above the bracket. **Continue to manual positioning** verifies completion, an attributed tool-sensor contact and the fresh active tool offset before dismissing that temporary run. The machine retains the measured offset; no manual length entry is needed. If the same fitted probe is already measured and active, choose **Use existing measurement**. No second tool-setter cycle is included in the anchor-contact run.
3. Keep the guide open and use Device alongside it to manually jog the probe over the solid top at the bracket's front-left elbow, clear of screws and holes. Aim 5 mm left and 5 mm forward of the inner corner, with the tip roughly 5 mm above the aluminium top. The guide shows the expected machine XY (**Anchor 1 + X−5, Y−5 mm**) and accepts a manually positioned start within 1 mm in each axis. Live target, current and adjustment readouts explain an out-of-tolerance start before Next or Run, without changing work zero. The guide stays beside the controls when switching tabs; selections remain while the app is open. This is fine calibration and still needs an approximately correct stored anchor.
4. Enter the **Estimated gap above bracket top** (0.1–5 mm) and the separate **Maximum left search · X−**, **Maximum front search · Y−** and **Maximum downward search · Z−** distances. These are total travel from each search's start, limited by the app to 0.4–10 mm, not a specification of safe probe deflection. Defaults are a 5 mm estimated gap and 6 mm limits. Downward search must exceed the estimated gap; the gap is also used for the nominal preview. Estimate conservatively, and verify the real clearances: a missing signal or wrong gap/geometry can still damage the probe. Never increase a limit automatically after a failed search.
5. After positioning, keep the machine stationary and spindle stopped. The guide automatically shows **Ready—touch the probe once, then remove the contact**. For a conductive rod, touch it once with a wire or metal contact connected to the machine table or bracket, hold for about two seconds and remove it. A loose conductive object alone may not complete the sensing circuit. The live Open/Contact indicator and reading counter show what the machine reports. Signal reading does not require the final Anchor 1 X/Y position; Run still checks that position. Jogging preserves a completed electrical check, and the guide automatically checks release at the new stationary position. Do not bend the rod or jog it into the bracket. For a mechanical probe, gently trigger it once, hold briefly and let it return. No clicking is needed at the machine. Return to the PC: **Probe signal verified** unlocks **Next**. Remove the testing contact, review the bounded travel and confirm the physical setup, then choose **Run bounded anchor probing** within two minutes. The original two-minute expiry still applies after jogging. This is one electrical signal test, without separate X/Y/Z tests, and it is not repeated immediately after tool setting.
6. The first top search uses the entered maximum downward distance at 30 mm/min; the second top touch is limited to 0.4 mm at 15 mm/min. It retracts 5 mm above the touched top, travels 10 mm into the pocket along each axis, descends beside the inner walls and takes two contacts on each wall. Side depth is at least 2 mm and at least the ball radius plus 0.5 mm. First side searches use the entered X/Y limits. After the short verified probe-away release, each wall withdrawal adds 2 mm of clearance; the slower second side touch is bounded to 2.4 mm at 15 mm/min. This allows the released travel plus clearance and does not enlarge the first-search limits. X is released and returned clear before Y. Every search must trigger and match the commanded movement and stopped machine coordinates before any subsequent travel or coordinate change. These six contacts set the active work origin.
7. The completed result in the guide offers **Save as Anchor 1**, locked to that target. Review old/new machine coordinates before **Write anchors**. The existing acknowledged, read-back-verified writer preserves the other anchors' offsets, so they move with Anchor 1. Choose **Finish calibration** to dismiss the temporary result. Reset and re-home after saving so firmware-owned moves use the new configuration. The guide never resets, homes or writes automatically.

Temporary runs use the ordinary program preparation, plate checks and machine job engine. Progress, failures, tool confirmation and Stop appear in the guide. Closing it during motion opens Job; **Continue Anchor 1 calibration** reopens the guide. Closing or reopening never starts or repeats motion. Stop cancels a pending start as well as an owned active run. A connection change refuses pending motion and stage continuation. A changed probe entry refuses use of a completed setter result. The frozen temporary session survives navigation while the app is open, without creating or changing project plates; normal machine program files and protocol logs can remain. Automatic bed cleaning is set to Off for these calibration runs; check that assist before the next machining job.

The preview starts at the checked XY and modeled bracket top plus estimated gap, with the retained probe and its radius. Its Z is nominal geometry, not a measurement of stylus length. The protected contact program has no tool change, clearance retract or added work-origin preamble before the first short search. It cannot be combined, remapped or preceded by a Stop-before. Editing the probe, diameter, bracket, original anchors or target invalidates it. Saved jobs from another connection cannot reuse the input check. Only a complete attributed result from the original device and unchanged anchor configuration can save the anchor.

This is fine calibration: the stored anchor must already be close enough to position above the correct solid bracket top and to move into its pocket. It cannot discover a misplaced bracket or recover unknown machine coordinates. It does not measure probe diameter or spindle alignment. The workflow is informed by [GabrielMaker's Anchor 1 calibration video description](https://www.youtube.com/watch?v=4rQWrt5rDqo); contact execution is owned by the app rather than native M480.8.

The separate **3D Probe Rod** is supported by this bounded Anchor 1 routine. Use **Open tool library** in the guide, save the **Makera 3D Probe Rod** catalog entry with its actual contact diameter, and close the library to return to the guide. Select that rod under **Connected XYZ probe**. Its profile is **X, Y and Z**, **Conductive rod**, without a laser pointer, and it uses the same T9999 slot. The supplied catalog deliberately leaves its diameter and other dimensions unknown because the source does not specify them. Only enter the contact diameter; the tool setter obtains the fitted length. Existing projects can add it from the catalog; new libraries include the entry. Custom XYZ probes can set **Contact method** in the tool editor, while older entries remain valid with an unspecified contact method.

Disconnect the wired Z probe and connect the rod's own cable. It needs a conductive contact path from the bracket top and both contacted inner faces to the aluminium table through pins, screws or another connection. A metal-looking or coated bracket is not proof of conductivity. Verify each actual face. For the automatically watched signal check, touch the rod once with a loose conductive contact connected to the actual bracket, hold briefly, then remove it; do not push or bend the rigid rod or jog into the bracket to test the signal. Clear loose leads before preparing the job. Bounds and live contact checks remain mandatory for the rod, and selecting it never sends commands. Do not reuse the broken mechanical probe's entry or use the damaged probe for verification. Physical rod execution with this sequence remains unverified. See [Makera's Z1 Quick Start, 3D Probe Rod](https://wiki.makera.com/en/Z1/QuickStart).

Conductive profiles without an assigned model draw a flat-ended rod rather than a ruby ball. Unknown dimensions still use nominal preview geometry; this is not a measurement of the fitted rod or a clearance guarantee.

## Effective probe diameter

Every XYZ probe setup offers **Probe tip diameter**, including Anchor 1, Z probing, picked-point positioning and probing, inspection, and the Prepare operation inspector. It shows that probe's saved diameter or an editable **2.000 mm** default when unknown. Enter the contact ball or conductive rod diameter, then choose **Save tip diameter** before continuing. This is an undoable tool-library edit: future operations, generated compensation and inspection calculations use the saved value. Existing calibrated values are retained, and running jobs keep their frozen tools. The control is unavailable during an active run. Routine-specific diameter and clearance limits still apply. A Z-only probe does not use lateral ball-radius compensation.

The tool editor labels the probe's main diameter **Probe tip diameter**. Choosing XYZ sensing for a new probe with an unknown diameter initializes it to 2 mm; known dimensions are preserved. Diameter calibration has its own editable **Initial probe tip diameter**, default 2 mm, and saves its computed effective diameter through the same library update.

The guide prepares protected physical Boss-X readings with the same actual input proof and step-by-step contact verification as Anchor 1. It does not execute native M480.10. Pasted-reading calculation and report export remain available. Hardware verification of the new bounded sequence is outstanding.

The four-step guide implements the known-width Boss-X method supplied with [GabrielMaker's diameter calibration video](https://www.youtube.com/watch?v=rj9dhoIGyUQ) and the user-supplied **3D Touch Probe Diameter Calculator - GabrielMaker.html**. The calculator's scripts are not embedded or executed. Pasted commands are parsed as data and are never sent to the machine.

1. Secure a reference with a known width along machine X, clear of the machine edges. The supplied bracket is nominally 15.000 mm wide; use a measured reference value when available. Do not leave it at its normal Anchor 1 position: the probe needs space outside both sides. The measured side faces are perpendicular to X.
2. Select the physical XYZ probe, fit and cable it and home the machine. If newly fitted or remounted, **Prepare tool-setter detection** and Run the separate setup job on Job. Otherwise reuse its existing active tool measurement. Dismiss that job's result, then manually position over the solid reference center, roughly 5 mm above its top. Defaults are 10 mm X offset, 2.5 mm side depth and initial D2.000. The offset must exceed half the width plus ball radius plus 1 mm. Side depth must exceed the complete ball diameter by 0.25 mm and remain clear of the table, screws and clamps.
3. Set the estimated top gap (0.1–5 mm) and separate maximum inward searches from the left (X+), right (X−) and downward (Z−) starts (0.4–10 mm). Defaults are 2.5 mm on each side and 6 mm down. Each side limit must exceed its estimated gap but remain shorter than the center-to-side offset; downward search must exceed the top gap. These are total commanded travel, not rated safe probe deflection. At the manually positioned stationary start, let the guide watch one touch and release automatically. No clicking while touching is needed. The same proof expiry, one-use and invalidation rules apply as Anchor 1. No tool change or remeasurement occurs after positioning.
4. Prepare reading 1, Run it on Job and reopen the guide **before Dismiss**. **Collect completed reading** uses the frozen run, its originating device, its probe and the attributed complete Boss-X contacts. Each successive job uses the previous reading's effective diameter, rounded to three decimals. The guide uses a separate calibration probe library entry; it leaves the original entry unchanged until Save. Reposition over the same reference center before each Run. Closing the guide retains its draft while the app is open; it is not an automatic background job.
5. Review all three readings, confirm that they are separate physical cycles on the selected probe/reference, and save the final effective diameter to the original probe. Save updates its diameter and appends calibration notes as an undoable library edit. Future generated probing NC takes that library diameter; already exported programs and a frozen Run do not change. Export the JSON report to retain raw contacts, inputs, provenance and results before closing the app. Saved diameter and notes persist through the normal tool-library persistence.

Each reading touches the top twice, records work Z0 and the manually positioned X0, raises 5 mm, travels to the left offset, descends beside the boss and touches inward twice. It releases, raises before crossing to the right offset, descends and touches inward twice, then releases, raises and returns to the original manual X center. First searches use the chosen limits; second touches are limited to 0.4 mm at 15 mm/min after a verified probe-away release of at most 0.2 mm and 0.1 mm additional clearance. Unlike the Anchor 1 wall withdrawal, the diameter routine retains this small clearance within its existing reference-offset envelope. Every contact is required and correlated before subsequent movement. The calculated center appears in the inspection report, but this calibration job leaves work X0 at the manual center; it is not a replacement for a feature-centering operation.

The preview starts at checked XY with the retained probe radius. A known-width schematic boss supplies nominal contact geometry; its height and Y extent are illustrative, not a measurement of the installed reference. The physical top is determined by actual contacts. A reading must run alone without tool remapping, added operations, Stop-before or work-origin preamble. The guide freezes the checked plan, device, tool and parameters and rejects collection if the frozen run differs.

Manual mode accepts one complete MDI log for each reading, including a single **M480.10 D… X… Y0 Z…** command and exactly six successful PRB reports after it: two top, two left and two right. Earlier TLO contacts are ignored because they precede that command. Ambiguous, mixed, failed and incomplete routines are rejected. Bounded collection also rejects reused run IDs, edited parameters and different devices. Editing a simulator reading does not remove its practice-only status. Pasted logs have operator-supplied provenance, which the app cannot verify.

The calculation follows the supplied calculator: left mean = average of both left contacts; right mean = average of both right contacts; contact span = right mean − left mean; effective diameter = span − known width. The result is the average of three effective diameters, rounded to 0.001 mm. For example 16.9735 − 15.0000 = 1.9735 mm, which rounds to D1.974. This differs intentionally from normal feature measurement, which uses the slower contact on each side.

Application checks require effective diameter 0.5–10 mm, side Y and Z spread at most 0.01 mm, at most 0.1 mm between the two X contacts on each side, and a final three-reading diameter range at most 0.02 mm. These are screening thresholds, not accuracy guarantees. Simulator readings can exercise the guide but cannot be saved as physical calibration. This is scalar X-derived compensation; Makera also applies that diameter to Y, whose response is not measured here. Keep the same stylus, mounting orientation and probing conditions; recalibrate after changing them. Effective diameter is compensation, not a claim that the physical ball changed size.

## Manual verification

- Inspect both bracket variants at the front-left anchor. The optional tool-setter job must measure and retract without travelling to the bracket. The contact preview must start at the manually checked XY and the modeled top plus estimated gap, and show the probe radius at its inner walls. Changing an X/Y/Z limit must change only that first search distance; removing limits from an old draft must require recreating it.
- Without commanding motion, verify that a permanently released input cannot complete the three-state check. Jogging must retain a completed electrical check but require a fresh stationary released read before Run, without extending expiry. Moving during an incomplete check, changing tools, reconnecting, another command or expiry must invalidate it. A steady untouched input does not establish that an unplugged probe works. The guide must see the actual contact and removal; no confirmation checkbox supplies this signal evidence.
- Inspect protected NC: no M6 or native M480, no added preamble/retract, one standalone operation, six bounded measuring searches and bounded probe-away release moves. Release reports must not count as measurements, and ordinary clearance must wait for verified release. Old drafts, changed reference geometry, tool remapping, multiple operations or changed anchors must block generation. Missing, failed or inconsistent contacts must never produce an anchor-save result.
- For diameter readings, inspect top/left/right bounded searches, the lift before crossing the boss, checked start and retained tool. Failed contacts must stop before the next travel. Simulator and pasted-reading calculations must reject incomplete, malformed or reused readings; simulated readings cannot be saved as physical calibration.
- Static build checks do not verify real stopping, wiring or accuracy. Physical verification of the new sequence is still outstanding; do not use the damaged probe for it.

A lost temporary run can be dismissed after reconnection once fresh telemetry reports Idle, no native program and spindle off. Dismissing clears only the ended run; it neither retries it nor accepts a disconnected measurement as verified. Review the fitted probe and explicitly restart or reuse its current tool measurement.

The signal panel names its actual waiting condition rather than combining tool, spindle and movement checks into one instruction. In the Z1's complete status report, an absent `O` field means height compensation is off; a present `O:0` means an active map with zero reported deviation. The firmware adapter retains that distinction, and signal proof, bounded probing and physical controller jogging require compensation to be explicitly off. Missing or malformed data is not accepted as proof. This follows [Makera's `Kernel::get_query_string`](https://github.com/MakeraInc/MakeraZ1Firmware/blob/main/src/libs/Kernel.cpp), which emits `O` only while `compensationTransform` exists.
